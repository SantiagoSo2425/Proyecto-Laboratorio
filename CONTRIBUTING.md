# Contribuir a Proyecto Laboratorio

Gracias por tu interes en contribuir.

## Requisitos

- Docker + Docker Compose
- Python 3.11+ (para pruebas)
- Flutter (opcional, si deseas desarrollo local del frontend)

## Preparar entorno

```bash
docker compose up -d --build
```

## Pruebas

```bash
pip install -r requirements-dev.txt
pytest -q
```

## Buenas practicas

- Usa nombres claros en commits.
- Evita cambios grandes sin discutirlos primero.
- Mantiene consistencia con las carpetas `app/` y `flutter_app/`.

## Pull Requests

- Explica el problema y la solucion.
- Incluye pruebas o evidencia de funcionamiento.
